# CSS Advanced Project

## Description

This project is part of the ALX Software Engineering curriculum and builds on the HTML Advanced project. The goal is to apply advanced CSS styling techniques to an existing HTML structure in order to match a professional design provided via Figma.

## Objectives

- Understand and apply advanced CSS concepts
- Use CSS to recreate a design from a Figma mockup
- Practice layout techniques such as Flexbox
- Improve responsiveness and visual hierarchy
- Learn how to interpret designer specifications

## Project Structure

- `index.html`: HTML structure of the webpage
- `styles.css`: CSS styling (to be added in subsequent tasks)
- `images/`: Assets used in the design (if applicable)

## Resources

- Figma design file
- Source Sans Pro font
- Spin Cycle OT font
